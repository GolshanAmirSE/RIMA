[ R | M Λ ] — fonts (optional)

The player uses two free fonts: Inter (English) and Vazirmatn (Persian).
It loads them from a fixed, versioned font server and then keeps them saved
on each device, so they look the same on every phone and computer.

To serve them from your own site as well, download these 3 files and put
them in this "fonts" folder (keep the names exactly):

  inter-latin-standard-normal.woff2
    https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.3.0/files/inter-latin-standard-normal.woff2
  inter-latin-ext-standard-normal.woff2
    https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.3.0/files/inter-latin-ext-standard-normal.woff2
  vazirmatn-arabic-wght-normal.woff2
    https://cdn.jsdelivr.net/npm/@fontsource-variable/vazirmatn@5.3.0/files/vazirmatn-arabic-wght-normal.woff2

Both fonts are free under the SIL Open Font License.
